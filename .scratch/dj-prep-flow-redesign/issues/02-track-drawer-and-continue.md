# 02: Track drawer and Continue flow

**What to build:** Let a DJ open any Pipeline track in a detail drawer, see its recommended next action, and use Continue to open the next track needing attention without losing queue context.

**Blocked by:** 01: Pipeline shell and actionable groups

**Status:** ready-for-agent

- [ ] Opening a track preserves the visible Pipeline context.
- [ ] The drawer shows the track details and one recommended next action.
- [ ] Continue selects the next actionable track in a stable order.
- [ ] Editing, candidate inspection, approval, and existing track actions remain available.
- [ ] Closing the drawer returns to the same Pipeline position.
