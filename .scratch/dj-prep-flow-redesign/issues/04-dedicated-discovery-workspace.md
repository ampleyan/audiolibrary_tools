# 04: Dedicated Discovery workspace

**What to build:** Move related-track exploration into a Discover destination where a DJ can choose one or more Pipeline tracks, tune similarity, inspect deduplicated results, and preview recommendations.

**Blocked by:** 01: Pipeline shell and actionable groups

**Status:** ready-for-agent

- [ ] Maximum results and minimum similarity score can be adjusted.
- [ ] Duplicate recommendations are removed.
- [ ] Recommendations can be selected clearly.
- [ ] YouTube previews remain usable inline with compact controls.
