# 01: Pipeline shell and actionable groups

**What to build:** Give the tool a Pipeline home that shows imported work in four actionable groups: Inbox, Needs attention, In progress, and Ready.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Pipeline is the primary navigation destination.
- [ ] Tracks appear in the correct user-facing group based on their existing state.
- [ ] Each group shows an accurate track count.
- [ ] Technical state names are not used as primary group labels.
- [ ] Web and Tauri editions show the same Pipeline concepts.
